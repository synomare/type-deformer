# Combination presets

120 original recipes, 12 families, 59 Operators. These are permanent built-in presets; user presets remain in their existing browser store.

The JPEGs are 600×370 thumbnails of native Type Deformer v66 PNG exports, produced for this project on 2026-09-07. No third-party artwork or generated replacement imagery is included.

The registry factors identical parameters into `common`. Merge `common` with a recipe’s `params` to restore its original v66 settings. Text, all letter states, layer order, opacity, and frozen moment are retained. The application helper in `preset-library.js` also supports applying a look to the current source while preserving its typography and document layout.
